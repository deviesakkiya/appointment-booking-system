# Appointment Booking System

## 📌 Project Overview

The **Appointment Booking System** is a simple and responsive web application developed using **HTML, CSS, and JavaScript**.

It allows users to enter patient information, select a doctor, choose an appointment date and time, and generate an animated appointment confirmation receipt. Each booking receives a unique appointment ID, and the receipt can be printed directly from the browser.

This project is a **frontend-only application**. It does not use a backend server or database, making it suitable for learning, demonstrations, and deployment through **GitHub Pages**.

## ✨ Features

* Appointment booking form
* Patient details
* Doctor selection
* Date and time selection
* Animated appointment confirmation
* Unique appointment ID
* Appointment receipt
* Print appointment receipt
* Responsive design
* Client-side form validation
* GitHub Pages compatible
* No backend or database required

## 🚀 How to Run Locally

### Option 1: Open directly

1. Download or copy the project files.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Double-click `index.html`.
4. The Appointment Booking System will open in your browser.

### Option 2: Using VS Code

1. Open **Visual Studio Code**.
2. Select **File → Open Folder**.
3. Select the `Appointment-Booking-System` folder.
4. Make sure the three files are in the same folder:

   * `index.html`
   * `style.css`
   * `script.js`
5. Open `index.html`.
6. You can run it directly in a browser or use the **Live Server** extension in VS Code.

## 🌐 GitHub Pages Deployment

GitHub Pages can publish a static website directly from a repository branch. For this project, the recommended source is the `main` branch and the repository root folder.

### Step 1: Create a GitHub repository

1. Sign in to GitHub.
2. Click **New repository**.
3. Enter the repository name:

```text
appointment-booking-system
```

4. Add the repository description:

```text
A responsive frontend appointment booking system built with HTML, CSS and JavaScript.
```

5. Choose **Public** if you want the project and GitHub Pages site to be publicly accessible.
6. Create the repository.

### Step 2: Upload project files

Upload these files to the repository:

```text
index.html
style.css
script.js
README.md
```

You can use **Add file → Upload files** and drag the files into GitHub.

### Step 3: Commit the files

1. Enter a commit message such as:

```text
Add appointment booking system
```

2. Commit the files to the `main` branch.

### Step 4: Open repository Settings

1. Open your repository.
2. Click **Settings**.
3. In the left sidebar, under **Code, planning, and automation**, click **Pages**.

### Step 5: Select GitHub Pages source

Under **Build and deployment**:

1. For **Source**, select:

```text
Deploy from a branch
```

2. For the branch, select:

```text
main
```

3. For the folder, select:

```text
/(root)
```

4. Click **Save**.

### Step 6: Wait for deployment

After saving, GitHub will build and deploy the site.

Return to:

**Repository → Settings → Pages**

When the deployment finishes, GitHub will show the live site URL in the Pages section.

Your project URL will normally follow this format:

```text
https://YOUR-GITHUB-USERNAME.github.io/appointment-booking-system/
```

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.
